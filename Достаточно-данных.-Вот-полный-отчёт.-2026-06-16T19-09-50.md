## Следующие шаги (приоритетные)

1. **Установить инструменты сборки:**
   - [CMake](https://cmake.org/download/)
   - [Visual Studio Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/) → компонент **"Desktop development with C++"**

2. **Клонировать исходники Stockfish:**
   ```
   cd devils-game/native
   git clone https://github.com/official-stockfish/Stockfish.git stockfish-src
   ```

3. **Собрать DLL:**
   ```
   cd devils-game/native
   mkdir build && cd build
   cmake .. -G "Visual Studio 17 2022" -A x64
   cmake --build . --config Release
   ```

4. **Добавить Gradle-проверку** наличия `stockfish_jni.dll` в `build.gradle.kts`

5. **Запаковать в JAR** (native DLL + NNUE файл)
