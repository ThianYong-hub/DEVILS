# MiMo Agent — Workspace Rules

## Git Commit Rules (STRICT)

### 1. ЗАПРЕТ на auto-snapshot коммиты
**НИКОГДА** не создавай коммиты с сообщениями вида:
- `[MiMo] Auto-snapshot: Before destructive command: ...`
- `[MiMo] Auto-snapshot: ...`
- Любые автоматические/резервные коммиты

Это системный механизм расширения — он сам делает такие коммиты перед выполнением команд. Если ты видишь такой коммит в `git log` — НЕ создавай похожие через `git_commit`.

### 2. Формат коммитов
Все коммиты должны быть осмысленными и описательными:
- `feat(chess): add EvalFile UCI option to Stockfish engine`
- `fix(loader): handle missing NNUE file gracefully`
- `refactor(engine): simplify StockfishBridge initialization`

### 3. НЕ делай лишних коммитов
- Не коммить без изменений
- Не коммить промежуточные состояния, если задача не завершена
- Один логический блок изменений = один коммит

### 4. Команды shell
Не оборачивай простые команды в коммиты. Выполняй `compileJava`, `findstr` и т.д. как проверочные команды — они НЕ требуют коммитов.
